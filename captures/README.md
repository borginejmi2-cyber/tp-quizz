# Captures d'écran du projet

Ce dossier contient les captures d'écran requises par le sujet du TP :

1. `question_initiale.png` : Première question avec son image, ses trois boutons, le score en haut à droite (0/5) et la barre de progression (0/5).
2. `bonne_reponse.png` : Réponse juste avec le message de confirmation vert et le score mis à jour.
3. `mauvaise_reponse.png` : Réponse fausse avec le message de correction rouge et le score inchangé.
4. `ecran_final.png` : Écran final affichant le score obtenu et le bouton **Rejouer**.

---

*Note : Pour ajouter vos captures réelles depuis l'émulateur Android Studio, effectuez des captures d'écran (`Ctrl + S` dans l'émulateur) et déposez les fichiers d'images dans ce dossier `captures/`.*
